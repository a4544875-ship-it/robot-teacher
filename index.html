🚀 引擎室（大人專用）

這個頁面目前不是在 Claude 裡打開（沒有偵測到 Claude 的聊天能力）。如果你有自己的 Anthropic API 金鑰，可以貼在這裡，讓「問老師」直接用你自己的帳號在這個瀏覽器裡運作。

  • 金鑰只會存在你這個瀏覽器（localStorage），不會送到別的地方或上傳到任何伺服器。
  • 每次提問會直接從你的瀏覽器呼叫 Anthropic 的 API，所以還是會被你自己的帳單計費，請自行注意用量。
  • 金鑰仍會留在瀏覽器的分析工具（開發者工具）可見範圍內 —— 不要在公用電腦或借別人的裝置上輸入。
